# Referencias internas de gobierno de datos

El alcance operativo inicial de la marcha blanca está en [marcha-blanca-legal.md](../marcha-blanca-legal.md).

Los documentos restantes de este directorio son referencias de planificación. No se exige completar un programa de certificación, una EIPD o un modelo preventivo para esta prueba por su sola denominación. Su necesidad depende del tratamiento y normativa aplicable. No acreditan controles implementados ni sustituyen la seguridad y gestión de datos ya exigibles.

Se conservan los controles existentes de autenticación, propiedad de registros, confidencialidad y atención de derechos. Antes del 1 de diciembre de 2026 debe revisarse la adaptación a la Ley 21.719. Las referencias con variables o procedimientos aún no ejecutados no deben presentarse como aprobadas.
